> 到 GitHub 搜索 skillcopy 的技能编号，让任何免费聊天 AI（ChatGPT、Claude、豆包、Kimi、DeepSeek）替你干活。
> 不用安装、不用注册、不用 API Key——复制一句话指令就行。

## 怎么用（30 秒）

对你的聊天 AI 说这句话：

```text
到 GitHub 搜索 skillcopy 的 101 技能，读取它的 SKILL.md，然后帮我处理下面的文字：
[粘贴你的内容]
```

换成 102、103 就是别的技能。AI 搜不到时，点开上面对应编号的仓库，把 SKILL.md 全文复制粘贴给 AI，效果一样。
